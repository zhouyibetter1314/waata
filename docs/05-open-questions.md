# 05 开放问题与待验证事项

## 待决事项

| ID | 主题 | 待决事项 |
| --- | --- | --- |
| Q-001 | 测试计划 | 是否支持编辑计划或人工确认后再执行 |
| Q-005 | 运行预算 | 为代表性场景记录模型、耗时、动作及令牌用量，评估默认配置 |
| Q-006 | 断言范围 | 是否加入语义断言，以及需要哪些可复核证据 |
| Q-007 | 证据和报告 | 是否支持报告导出、额外存储后端及可安全交付的原始 Trace |
| Q-008 | 共享部署 | 谁负责配置目标授权、网络出口和有外部副作用的功能动作 |
| Q-010 | 工程工具与流程 | 确定 CI 必跑检查、人工验收记录归档方式及主分支保护 |
