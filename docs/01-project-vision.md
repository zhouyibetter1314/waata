# 01 项目愿景

WAATA 为开发者和测试工程师提供自然语言驱动的 Web 功能测试。测试人员在授权环境中指定目标页面、前置数据和预期行为。系统规划并执行测试，记录可复核的操作、断言和证据。测试人员可以复跑场景，核对页面变更后的行为。

## v0.1 范围

- 从 Web 页面提交任务，或从浏览器场景库批量提交。平台提供排队执行、进度、取消、报告和证据查询。
- 通过独立 Python 包规划用例、执行受控浏览器动作、检查结果和生成报告。
- 在测试人员选定的授权站点验收，通过运行状态记录技术结果，通过测试判定记录实际行为是否符合预期。

全站探索、视觉回归、压力测试、定时执行、集中式场景库和团队权限管理属于后续范围。[需求](02-requirements.md) · [架构](03-architecture.md) · [开放问题](05-open-questions.md)
