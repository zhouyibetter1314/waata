# 05 开放问题与风险

这些条目跟踪 v0.1 开发与部署中待验证的事项。需求、架构和接口变更分别同步到 SRS 与验收、ADR 和正式契约。

## Q-001 v0.1 范围

评审登录以外的功能是否进入首版，以及测试计划是否需要人工确认或编辑。用首条端到端场景的交付成本决定扩展范围。

## Q-002 公共接口与状态

按 C1 和 C2 联调 Run ID、生命周期、用例判定、错误和取消。在同一个 Mock 场景中验证三层的状态与字段转换。

## Q-003 队列持久化与恢复

首版从 PostgreSQL 的 `queued` 记录领取任务。部署仍需确定 Worker 存活判定、失效接管和取消通知方式。用重启和中途取消演练验证旧执行者停止、资源清理及终态收敛。数据库保证见 [C6](../contracts/database/c6-platform-persistence.md)。

## Q-004 运行和用例隔离

运行之间采用独立浏览器会话。评审同一 Run 中用例如何重置登录态和测试数据，避免顺序依赖。用交换两个登录用例的执行顺序与并行复跑验证隔离行为。

## Q-005 运行预算与基线

先记录代表性场景的执行时间、步骤数、模型用量和并发资源占用，再确定默认值和上限。记录模型、环境和数据条件，验证达到上限时任务如何收尾。

## Q-006 结果可信度

确定何时允许语义判断、证据缺失如何归类、模型结果如何与确定性断言一起呈现。用正常站点、回归站点和执行异常建立对照。

## Q-007 证据和报告

按 C5 的授权与脱敏规则配置存储后端、保留期限、大小上限、Trace 采集策略与报告导出范围。用受控夹具验证实际可保存的数据。

## Q-008 授权目标和测试凭据

明确调用方如何证明目标授权、如何配置允许的域名与动作、如何提供测试凭据。使用受控站点检查重定向与跨域导航的处理，并明确有外部副作用的操作如何审批。

## Q-009 事件传递与重连

按 C4 配置保活间隔和异常恢复。用 Mock 事件中断和重复投递验证重放、去重与终态查询。

## Q-010 工程工具与流程

待确定后端实现的测试基线、CI 必跑检查和主分支保护规则。现有前端检查与提交钩子见 [前端说明](../apps/web/README.md#验证)和 [团队协作规约](../CONTRIBUTING.md)。
