# 02 软件需求规格说明

状态为评审稿，供团队裁剪 v0.1 范围。P0 是核心能力，P1 是平台集成阶段规划的能力。

## 使用场景与术语

开发者或测试工程师在受控测试环境中提供目标地址、自然语言目标、预期行为与必要的测试数据。一次提交对应一次运行（Run）。计划包含一个或多个测试用例（Case），用例通过步骤（Step）与断言验证预期行为。证据指可复核的观察结果及其引用，例如实际 URL、界面提示、可见控件、截图或浏览器 Trace。

运行生命周期描述任务调度和执行进度。用例判定描述目标应用的实际行为与预期是否一致。一次正常完成的 Run 可以报告某个业务断言失败。

| ID | 优先级 | 需求 | 验证 |
| --- | --- | --- | --- |
| FR-001 | P0 | 接收目标地址、自然语言测试目标与预期行为，接受有效请求并关联唯一 Run ID。 | [AC-01](04-acceptance.md#ac-01-提交与规划) |
| FR-002 | P0 | 将测试目标转换为结构化测试计划。每个用例包含目标、前置条件、预期结果与可执行的验证点。 | [AC-01](04-acceptance.md#ac-01-提交与规划) |
| FR-003 | P0 | 使用 Playwright 在授权环境中观察页面和执行用例所需的功能操作，取得操作结果与新的页面状态。 | [AC-02](04-acceptance.md#ac-02-受控站点执行) |
| FR-004 | P0 | 根据预期与实际证据判定用例结果。缺少证据、执行受阻或发生技术错误时，结果应体现实际原因。 | [AC-03](04-acceptance.md#ac-03-断言与失败归因) |
| FR-005 | P0 | 生成结构化结果，记录用例、步骤、断言、异常与可引用的证据，并关联到同一个 Run。 | [AC-04](04-acceptance.md#ac-04-报告与证据) |
| FR-006 | P1 | 在平台查看运行状态及执行进度。 | [AC-05](04-acceptance.md#ac-05-平台端到端) |
| FR-007 | P1 | 在平台查看报告、访问关联证据。报告导出方式由团队评审。 | [AC-05](04-acceptance.md#ac-05-平台端到端)、[Q-007](05-open-questions.md#q-007-证据和报告) |

## 非功能需求

| ID | 质量属性 | 需求 | 验证 |
| --- | --- | --- | --- |
| NFR-001 | 可靠性 | 模型或浏览器异常、超时、取消等应有可识别的结束结果。运行结束时应清理本次运行持有的浏览器资源。 | [AC-06](04-acceptance.md#ac-06-错误与资源边界) |
| NFR-002 | 可观测性 | 按 Run ID 追踪计划、模型调用、浏览器动作和判定。用例及步骤事件应关联相应的用例与步骤。 | [AC-04](04-acceptance.md#ac-04-报告与证据) |
| NFR-003 | 可维护性 | 独立 Python 包可在 FastAPI 外使用。应能注入模型、浏览器与观测替身，独立验证核心流程。 | [AC-07](04-acceptance.md#ac-07-独立使用与可复现性) |
| NFR-004 | 授权与数据保护 | 浏览器执行层限制在授权目标和允许动作范围内。测试运行隔离会话，凭据及敏感页面数据应从普通 Prompt、日志、报告和 Trace 脱敏。 | [AC-06](04-acceptance.md#ac-06-错误与资源边界) |
| NFR-005 | 可重复性 | 记录目标环境、用例前置条件、有效配置和证据引用，使同一测试夹具可复跑并对比结果。 | [AC-07](04-acceptance.md#ac-07-独立使用与可复现性) |
| NFR-006 | 资源控制 | 运行受时间、用例数量、步骤、模型用量和并发限制。具体阈值由基线实验确定。 | [AC-06](04-acceptance.md#ac-06-错误与资源边界)、[Q-005](05-open-questions.md#q-005-运行预算与基线) |

## 外部接口与约束

Vue 通过 FastAPI 创建和查询任务，FastAPI 通过 WAATA 的公共 Python 接口执行任务。WAATA 通过注入的模型、浏览器及观测接口访问外部能力。后端向前端传递状态、报告和授权的证据引用。接口的详细设计与来源见[契约目录](../contracts/README.md)。

测试环境应允许团队重置数据和验证结果。v0.1 的验收基线使用自有演示站点、固定假数据和可控的正常与回归版本。尚待确定的字段、协议与运行策略集中在[开放问题](05-open-questions.md)。
